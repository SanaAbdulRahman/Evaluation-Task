# Experienceship Full-Stack Web Application - (Evaluation -task)

This is a responsive full-stack web application built using **React + Vite**, **TypeScript**, **Material UI**, and the **React Context API** for state management. The application integrates with a real-world API (documented via Postman).

## Features

-  Built with **React + Vite** and **TypeScript**
-  Sleek and responsive UI using **Material UI (MUI)**
-  Integration with real-world API (via Postman docs)
-  Global state handled using **React Context API**
-  Strongly typed with TypeScript for better maintainability

## Tech Stack

**Frontend**
- [x] React + Vite
- [x] TypeScript
- [x] Material UI (MUI)
- [x] React Context API
- [x] Axios or Fetch (for API calls)
- [x] React Router DOM

**API Integration**
- External API (as per Postman collection provided)
- Axios used for REST API requests
